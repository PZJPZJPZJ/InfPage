# TVBox:安卓电视工具
## 配置教程
1. 通过USB或ADB安装[TVBox空壳](#空壳下载)
2. 打开空壳APP进入设置
3. 在点播输入[接口地址](#接口地址)
4. 点击确定完成输入并返回到主界面
