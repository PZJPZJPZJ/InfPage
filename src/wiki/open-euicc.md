# OpenEUICC:开源eSIM写入工具
## 官方地址
- <https://gitea.angry.im/PeterCxy/OpenEUICC>
## 使用方法
1. 购买9sim、estk等可写入SIM卡
2. 在安卓设备安装OpenEUICC软件
3. 打开软件检测兼容性
4. 购买eSIM套餐并使用软件扫描运营商提供二维码
