## 包管理工具
### Yarn包管理工具
```shell
# 使用npm安装
npm install -g yarn
# 初始化项目
yarn init
# 添加依赖包
yarn add [package]
yarn add [package]@[version]
yarn add [package]@[tag]
# 移除依赖包
yarn remove [package]
```
### pnpm包管理工具
```shell
# 使用npm安装
npm install -g pnpm@latest
```
